# 地図ボス逃亡時の踏破・調査完了修正

確認日：2026-10-19。対象：地図探索V2。

## 原因

ボスマスへの移動時に `recordSurvey` が踏破情報を更新・保存し、戦闘開始時には調査完了演出だけを `deferredSurveyNotice` へ保留していた。逃亡処理は戦闘状態を解除するだけで座標と保留演出を戻していなかった。さらに通常敵の勝利後も保留演出を再生するため、ボス未撃破でも300/300となり、その後の雑魚戦勝利で調査完了が表示された。

## 修正

- 戦闘対象の未撃破ボスマスは、接触時には新規踏破を記録しない。通常ボス・Lv100特殊ボス共通。
- 撃破確定後にボスマスを記録する。通常ボスは討伐報酬の保存成功後に実施する。金箱がある場合は既存どおり金箱演出の後に調査演出を表示する。
- ボス逃亡時は生成済みボス部屋の入口側マスへ一歩戻す。座標と描画座標を同期し、向きは維持する。移動に伴う追加の環境ダメージ・気配・松明消費は発生させない。
- 逃亡時に保留演出を解除し、通常敵勝利ではボス用保留演出を再生しない。
- 戦闘のない特殊テーマLv99以下の既存導線と、過去の周回の踏破記録は維持する。

既に保存された踏破情報は自動削除しない。過去の正当な踏破と今回の不具合で得た踏破を、現在のビットマスクだけでは区別できないため。既存の300/300データを299/300へ戻す移行処理は含まない。

## 検証

ボス接触・逃亡で99/100・299/300を保持し、再戦勝利で300/300になること、戦闘中のJSON中断再開、過去に調査完了した地図の保持、実運用の戦闘終了関数での後退・報酬非付与・後続雑魚戦での演出抑止を回帰テストで確認する。既存の金箱→調査演出、甲虫王・三女神・保存再試行のテストも対象。
