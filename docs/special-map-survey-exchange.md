# 探検家テント：調査報告・スタンプ交換

実装日：2026-10-15

## 仕様

- 探検家テントの「調査報告」を有効化。初回は歓迎会話、スタンプ帳の保存、入手演出、説明の順。
- スタンプ帳と説明完了を別々に記録。説明途中で終了した場合は説明冒頭から再開し、帳面を重複付与しない。
- 入手演出はポップアップと `juuyou-item.mp3` を同時開始し、終了後に `fanfare.wav`。実ファイル名は `juuyou-item.mp3`。
- 挨拶はテント入場時の背景に合わせ、01f＝朝、01e／01d＝昼、01c＝夜。
- メニューは上段「報告／交換／戻る」。一覧は5件／ページ、上下端からソートへ移動可能。
- 既存V2の調査記録300／300で1p。同一content IDにつき一度。署名違い、削除・再登録でも重複受領しない。報告した地図は残る。
- ボスマスが最後の場合の、討伐後に調査完了を処理する既存の順序は変更していない。報告側で未完了の調査を補完しない。
- 一覧には調査完了かつ未報告の地図のみ表示。同内容の別署名地図は一件にまとめる。
- 報告確定はポイントとcontent ID履歴を一度の保存にまとめる。保存失敗時は巻き戻し、成功演出を出さない。
- 報告演出：黒オーバーレイ、ファンファーレ、白い「報告完了」（k8x12）と押印SE付きスタンプ、2秒保持、350msフェード。スタンプは右上がりと光彩付き。

2026-10-19価格改定：300マス踏破の平均約9分という実測を基に調整。刻印100→15p、ツァウバートランク300→10p、アルハイルミッテル600→30p、靴250→40p。お香1p・デバイス1000pは維持。探索時間換算は順に135分・90分・270分・360分。全快薬の頻繁な交換を抑え、デバイスは長期目標として残す。デバイス専用の交換確認台詞を追加し、詳細欄の効果説明は維持する。

- カテゴリ順・ポイント昇順・ポイント降順でソート。所持ポイント表示。
- ポイント不足、所持上限、靴の交換済み／所持済みはグレーアウト。キー操作で決定した場合も再検査。
- ポイント消費・アイテム付与・一度限り記録をまとめて保存。失敗時は全て戻す。
- 交換後はファンファーレのみ。ポップアップなしで同じ一覧の選択位置へ戻る。

## 引き寄せのお香

- 通常奈落／V2地図迷宮で使用可能。気配上昇量を2倍にしてからカード・スキルの軽減を適用。
- 通常の明るいマスで基礎上昇6なら12になるため、100到達の目安は17歩から9歩。暗さや軽減等によって変わる。
- 奈落は区域移動または帰還まで。V2は探索終了まで継続し、階層移動や中断保存で維持。
- 魔除けのお香と排他、最後に使った方が有効。同じお香の重ね掛けは消費せず拒否。
- 退魔の護符の気配抑制中は上昇しない。抑制終了後に引き寄せ効果が働く。
- 「俊敏俊足」など、カードだけで気配上昇が無効になる場合は使用不可。`boo.wav` と「気配上昇なしカードセット中」の案内を表示し、消費しない。
- V2では通常奈落の状態へ効果を書き込まない。保存失敗時はインベントリとセッション効果を巻き戻す。

- `keyItems.owned.stamp_book`：貴重品。

- `specialMaps.surveyShoesExchanged`：靴の交換履歴。所持品を削除しても残る。

- V2セッションの `attractingIncenseActive`：中断保存対象。
