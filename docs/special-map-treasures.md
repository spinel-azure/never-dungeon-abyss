# 地図迷宮の配置宝箱（内部仕様）

2026-10-20。通常V2の地図Lv91～100、密林/砂漠/結晶/漆黒に適用。

- 各階、赤1～3個（等確率）と黒1個。個数・位置はSEEDと階番号の専用ストリームで固定。既存地形/階段/金箱/敵分布のストリーム・構造fingerprintは変更しない。
- 階段、金箱、ボス部屋とその入口マスを除外し、赤黒の重複配置なし。黒箱は表示のみで開封不可、報酬/開封記録を付けない。対象外Lv/テーマと特殊金地図は変更なし。
- 赤箱の中身（中薬/大薬/防具）：Lv91～99は結晶漆黒40/10/50、密林砂漠35/10/55％。Lv100は25/15/60、20/15/65％。
- 防具当選時：密林結晶=僧侶/魔術師、砂漠漆黒=戦士/盗賊。2職4部位を各12.5％。転生0は紫晶/幻晶/白晶/星晶、1～3は現在の回数に対応する転生シリーズのみ。
- 強化値0/1/2/3：Lv91～99は60/25/10/5％、Lv100は40/30/20/10％。防具当選後の条件付き確率。
- 中身乱数はSEED・冒険UUID・箱IDの専用ストリーム。冒険UUIDは既存保存に含まれ、未開封時点のロードでも同じ結果。新しい周回ではUUIDが変わるため再抽選。再抽選でも同じ結果になることはある。
- 開封前に確定報酬を保存。演出完了コールバックで冒険用ロット袋と開封状態を同じスナップショットに保存し、保存失敗時は付与/開封を戻して再試行。同じ箱は二重付与不可。
- 中断保存にtreasureStatesを追加。旧保存で未定義なら空として扱う。既存冒険にも箱配置を再構築し、地形fingerprintの互換性維持。帰還/敗北時のロット袋処理は既存に従う。奈落のロット袋と混同しない。
- js/special-map/treasures-v2.jsに配置・抽選・確定処理を分離。黒箱の報酬設定は今後この経路に接続し、現段階では中身を捏造しない。刻印/カードの既存報酬演出・金鍵箱とは別経路。

検証：200SEED×4テーマ×3階の個数/配置/除外/構造不変、対象外テーマ/90以下、全転生段階/強化率/部位抽選、保存失敗/中断/旧保存/重複/周回、歩行接触→確認入力、帰還時の正規鑑定をNodeで確認。ブラウザはテスト用にキャラクター・位置を設定し、本編の赤箱開封/保存/ロード/黒箱調査をPC1280×900・スマホ相当390×900で確認。実端末/自然プレイ全階周回は未検証。

## 赤箱からの刻印金箱（2026-10-21）
対象は既存通常赤箱のLv91～100、green/yellow/crystal/black。赤箱ごと1%で金箱化し、剛力/叡智/疾風/技巧/幸運の刻印を各20%で1個。転生条件なし、既存効果量維持。通常赤箱報酬との二重付与なし。独立した冒険ID/箱ID乱数を使用し確定結果を保存。旧確定箱は維持。黒箱由来の猫武器金箱と鍵金箱は別処理。
