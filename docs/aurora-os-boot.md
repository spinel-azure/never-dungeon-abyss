# AURORA OS boot presentation

2026-10-31。独立した起動演出のみ。ハッキング・三女神戦・通常進行には未接続。音声・セーブ処理なし。

## 表示

ユーザーの追加指定により、論理サイズは960×540（16:9）。1600×900の dungeon_event_28.avif をCanvas 2Dへ描く。既存の960×540描画に合わせ、imageSmoothingEnabled=false と image-rendering:pixelated を使用。背景の枠内に40個の紫色セグメントを点灯する。枠内座標は x=360, y=371, width=240, height=15。文字はk8x12、読み込み失敗時は等幅フォント。

満タン到達後、約0.25秒で淡い紫色の光がゲージの周囲へ広がる。文字や装飾枠をぼかさず、終了時の暗転と一緒に消える。

0.3秒暗転→3.5秒で起動→0.8秒完了表示→0.3秒暗転。進捗の折れ点は0/800/1500/2300/2800/3300/3500ms、0/35/70/90/95/95/100%。requestAnimationFrameの時刻から計算し、FPSに依存しない。

モーダルdialogで既存HUDと操作を覆い、既存要素を削除・リサイズしない。終了時にdialogを削除しフォーカスを戻す。画像ロードは5秒で打ち切り、失敗はfalseを返す。dispose()でもfalse。通常完了はtrue。タイマー・フレーム・イベントリスナーを破棄する。

## デバッグ

簡単起動：リポジトリ直下の `AURORA-OS-Preview.cmd` をダブルクリック。ローカルサーバーを自動起動し、既定ブラウザでプレビューを開く。既に起動中なら再利用。サーバーはバックグラウンドで動作する。Node.jsがPATHに必要。


リポジトリで `node tools/dev-server.cjs 4173` を実行し、`http://localhost:4173/tools/aurora-os-preview.html` を開く。「AURORA OSを再生」で開始。通常ゲームのメニューには追加しない。

Enter / Space / Z、標準ゲームパッドのA、画面タップで完了へスキップ。完了状態で再入力すると終了。キーリピート・ゲームパッドの押しっぱなしを抑止し、300ms以内の連打は無視する。

## 将来の接続

`createAuroraBoot({anchor, imageUrl?})` の anchor に既存ゲーム画面要素を渡すと、その幅・位置に合わせる。省略時は画面中央に16:9で表示。

呼び出し側はゲームのシミュレーションと既存ゲームパッド処理を停止してから `await boot.play()`。抽象入力を利用する場合は `handleInput(action)` に最優先で渡し、既存のゲーム操作へ流さない。内蔵ゲームパッド検出との二重送信を避ける。画面破棄時は `dispose()` を呼ぶ。今回はゲーム本体への接続は実装していない。

## 検証

Node全件テストと、PC1280px・タブレット768px・スマホ390pxのEdgeブラウザテスト。ゲージ95%・完了時の画像はTEMPへ保存。フレーム進行、キースキップとリピート抑止、模擬ゲームパッド入力、タップ、呼び出し元復帰、画像失敗、中断を検証。実機iPhone・物理ゲームパッド・30fps実機描画は未確認。30/60fpsは同じ時間関数をサンプリングして確認。
