# 特殊地図 Phase 2A

## 動作確認手順

1. 冒険者をロードし、デバッグ3ページ目の「探検家テスト」をONにする。
2. 奈落入口→探検家テントを開く。初回は地図署名を登録する（例：†ルル）。
3. Bで奈落入口へ戻り、デバッグ3ページ目で「未鑑定地図を1枚入手」。自動保存される。
4. テント→地図鑑定で地図を選択する。名前とLvはまだ表示されない。
5. Aまたは確認ボタンで短い鑑定会話を進める。最後の確認で保存・自動登録し、詳細を表示する。
6. 地図整理で登録済み地図を確認する。リロード後も保持される。

再読み込みで探検家テストはOFFに戻る。地図データは残るので、再度ONで閲覧できる。
地図一覧は最初のタップで選択、次のタップで詳細。戻る／確認ボタンは1回で実行。
キーボード・ゲームパッドは既存のA/Bと方向操作。署名入力は文字入力欄を使用する。
署名は初回のみ。4文字を超えても切り詰めずエラーとする。
地図登録（共有コード）、削除、入場は未接続なので、登録10件に到達後は新規原本の鑑定ができない。

## データと仮生成

保存先は通常スナップショットの `character.specialMaps`。

```text
dataVersion: 1
discovererName: NFC正規化した署名
unidentified: 最大3件
  discoveryId / rulesetVersion / seed / discovererName
registered: 最大10件
  上記原本情報 + id / cleared
```

旧セーブには空状態を補う。地図専用の別ストレージキーは使用しない。
署名は前後空白除去・NFC後、1–4文字。ひらがな、カタカナ、BMP漢字、半角英数字、
`☆ ★ † ・ ー ! ?` を許可。絵文字・BMP外・制御文字等は不可。
原本IDは `[生成版, seed, 署名]` のJSON文字列で区切り衝突を避ける。
同seed・別署名は別原本。完全重複は上限より先に判定し、確認後に未鑑定のみ消費する。

生成版 `phase2a-1` は正式迷宮V1と区別した仮仕様。
地図名・Lvは版と16bit seedから算出し、署名に依存しない。
正式生成器導入時にこの版を正式V1へ黙って読み替えない。
未鑑定入手時だけ乱数を使い、鑑定では保存済み原本を読む。
3枚上限は乱数取得より前に判定する。
従来のPhase 1固定サンプルは実画面から使用しない。

## 保存の確定点

操作を純粋関数で計算→新しい冒険者へ丸ごと差替え→既存saveGameを実行する。
書込み失敗／例外なら操作前の冒険者へ戻す。未鑑定削除だけを先行して保存しない。
`writeGame` の本保存書込みを確定点とし、確定後のtemp削除・更新通知の失敗は保存失敗にしない。
これにより、確定済みの地図をメモリ上だけ未鑑定へ戻す事故を防ぐ。
temp・backup・currentの書込み失敗と確定後エラーを自動テストで検証する。
