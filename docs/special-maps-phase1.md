# 特殊地図 Phase 1

## 今回の実装範囲

奈落入口の下段に「探検家テント」「地図探索」「空欄」を配置する。
本編の解禁条件は未接続のため、通常時の前二つは `？？？`・選択不可。
デバッグモード3ページ目の「探検家テスト」をONにしたときだけUIを解禁する。
この設定はメモリ上だけで保持し、再読み込み／NEW GAMEでOFFになる。
遭遇・依頼フラグや保存形式は変更しない。プレビュー中の保存位置は奈落入口として扱う。

- テント：地図鑑定／地図登録の案内画面、仮地図整理、戻る。
- テント背景：開いた時点の端末時刻で05–07時=f、08–16時=e、17–18時=d、それ以外=c。
  `images/background/dungeon_01*.avif` を使用する。
- 地図探索：`circle.avif`、5件一覧と最大2ページ、詳細画面。
- 一覧：↑↓選択、←→ページ、A詳細、B戻る。ポインター操作は初回選択・2回目詳細。
- 詳細：Aは未接続の案内のみ。Bで元のページ・選択位置へ戻る。
- 仮データ件数ボタン、またはL/Rで0→1→5→6→10件を切り替えられる。
- 長い名前は**仮表示案**として一覧で省略し、詳細で全文を折り返す。生成名の長さ制約は未確定。

転送門の処理・選択状態には手を加えず、既存CSSを土台に専用UI／状態を分離した。
仮データには低／高Lv、長短名、同seed7291・別発見者の例を含む。
生成、鑑定、共有、削除、特殊迷宮への入場、戦闘、報酬は未実装。

## 次Phase以降の確定方針（今回未実装）

- V1は16bit seed（0–65535）。生成ルール版＋seedで内容を固定。
  生成コードだけでなくテーマ・敵候補・名称表・宝箱表・危険度計算も版管理する。
- 原本識別は生成ルール版＋seed＋NFC正規化済み署名。
  同内容・別署名は別原本。完全重複は既存記録を保持し、新しい登録枠を使わない。
  重複判定は登録10件上限の判定より先に行う。再抽選しない。
- 登録10件、未鑑定3件。調査達成時に報酬ID・seed・生成版・署名を固定する。
  満杯なら依頼側の未受領報酬として保持し、受取完了まで次の継続調査は不可。
- 鑑定は既存の内容を公開する操作。重複時の確認後消費や通常の自動登録は、
  未鑑定の削除と登録状態を一つの保存単位で確定させる。
- 地図署名は冒険者名と別の1–4文字。前後空白除去→NFC→検証。
  BMPの日本語・英数字・許可記号（☆ ★ † ・ ー ! ? 等）。
  絵文字・制御／不可視文字・異体字セレクタ・残存結合文字・BMP外は不可。
  超過時は切り詰めずエラー。発見時の署名を原本へ固定する。
- コード候補：形式版1byte＋生成版1＋seed2＋署名長1＋UTF-16BE署名最大8＋検証8。
  合計最大21byte＝Base64URL28文字、接頭辞5文字なら33文字。
  `-` はデータなので一律削除しない。検証方式／許可文字の厳密な一覧はPhase 2で実装前に確定。
- 削除は確認を挟む。再登録で原本は戻るが踏破・探索・メモ・お気に入りは復元しない。
- activeSessionは最大1件。同地図は続き／再探索、別地図開始は旧状態破棄の確認。
  中断中の地図削除は探索終了後。戦闘中の切替・削除は不可。
- 通常奈落と特殊迷宮の探索状態は別。最深到達・測量・ストーリー・ボス・転送門等を
  特殊迷宮で進めない。EXP・G・許可された通常ドロップは冒険者へ持ち帰る。
  報酬と取得済みフラグを同じ保存単位に含め、二重付与を防ぐ。
- NEW GAME+：署名・登録地図・発見者・お気に入り・メモ・踏破記録・未鑑定を引継ぎ。
  未受領調査報酬・activeSession・探索途中状態は破棄する。
- 公開前に全65536 seedの到達性・固定配置・宝箱・生態系分布を検査する。
  稼ぎ効率は職業／装備／経路等の条件付き推定と区別する。
  特定seedの優遇はせず、共通生成規則を調整して全件再検査する。
