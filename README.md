# NEVER DUNGEON : ABYSS

> THE MISSING QUEEN AND THE MYSTERIOUS CAT

![NEVER DUNGEON : ABYSS](images/screenshots/nda_ss_01.avif)

**NEVER DUNGEON : ABYSS（NDA）** は、ランダム生成される疑似3Dダンジョンを探索するブラウザRPGです。

[Never Dungeon Engine Ver.1.0](https://github.com/spinel-azure/never-dungeon-engine)をベースに、戦闘、職業、成長、装備、町、シナリオなどのRPG要素を開発しています。

現在のバージョンは **MVP1.0** です。

## Play

ブラウザからプレイできます。

**https://spinel-azure.github.io/never-dungeon-abyss/**

PC、スマートフォン、タブレットに対応しています。開発中のため、仕様やセーブデータ形式が変更される場合があります。

## Current Features

- 全セルへの到達保証
- Canvas 2Dによる疑似3Dレイキャスト描画
- 扉、階段、階層移動
- フロアごとの壁・床テーマ
- 霧、暗闇、たいまつ
- 気配ゲージ
- コンパス、ミニマップ
- NPCイベントとタイプライター会話
- 通常エンカウントと不意打ち、敵の先制行動
- 赤・黒・金・紫の宝箱とThree.jsによる開閉演出
- 石つぶて、石弓、毒針の宝箱罠と解除・回避判定
- 罠解除結果のポップアップ演出
- 踏破済み経路を使ったオート帰還
- 階層移動時のSE、暗転、フェード演出
- エンカウント時のズーム・フェード演出
- ダンジョン探索BGMと、SE・BGMの独立音量調整
- 通常戦闘、タイトル、施設ごとのBGM切り替え
- 戦闘不能時のゲームオーバージングルと専用演出
- 指定階層に出現し、探索ごとに一度だけHP・SPを全回復できる癒やしの噴水
- 癒やしの噴水を利用した際の、たいまつゲージ全回復
- 複雑な錠前をDEX依存で解錠する、ランダム配置の黒扉小部屋
- イベント小部屋の場所を未探索でも確認できるミニマップの「E」マーカー
- ギルド依頼の進行に応じて解放される黒箱と、階層ごとに異なる戦利品
- B10F到達後に利用できる、ダンジョン入口からの転送門
- 戦利品を一時保管し、帰還時にまとめて鑑定・収納するロット袋
- B30F～B39Fの赤い壁・床・霧と、専用装備で無効化できる火炎床ダメージ
- B40F～B49Fの氷壁・床・霧と、専用装備で無効化できる凍結床ダメージ
- B50F～B59Fの森林壁・床・霧と、区域固有の障害物・イベント小部屋
- B60F～B69Fの砂漠、B70F～B79Fの激流、B90F～B99Fの漆黒区域テーマ
- 砂漠区域の流砂・オアシスと、激流区域の方向付き水流ギミック
- 区域ごとに変化する通常敵、複数敵編成、属性相性、状態異常攻撃
- B90F～B99Fのたいまつゲージ強制消失と、専用カードによる視界・ミニマップ効果の維持

- 帰還階層に応じた深層帰還ボーナスと精算画面

- 戦闘不能時の寺院での蘇生

- 到達階層とボス撃破に応じて入荷する、各職業専用の強化防具

- 進行に応じた商店商品の追加と割引機能
- 寺院での治療、寄進、キャラクター名の変更
- 最大3件まで同時受注できるギルド依頼
- 現在25件のギルド依頼を実装済み
- 依頼受注・報告・履歴を確認できるギルドメニュー
- 酒場の会話と、進行状況に応じて追加・更新される噂話

### キャラクター

以下の4職業から選択できます。

| 職業 | 特徴 |
| --- | --- |
| 戦士 / WARRIOR | 高いHP・STR・DEFを持つ物理戦闘型 |
| 盗賊 / THIEF | 高いAGI・DEXと短剣の2回攻撃を活かす技巧型 |
| 僧侶 / PRIEST | 回復、守護、防御貫通攻撃を扱う安定型 |
| 魔法使い / MAGE | 高いINTと属性呪文を扱う魔法戦闘型 |

- STR / INT / AGI / DEX / LUCによる能力値
- HP / SP / DEF
- 職業別の初期能力値、初期装備、初期スキル
- 装備補正を含むステータス表示
- 詳細ステータス表示
- 装備・カードによる最大HP・SP補正の色分け
- 毒状態と歩行毒ダメージの専用表示
- アイテム、貴重品、装備品を分類したインベントリ
- 倉庫へ預けるスタック品の数量指定
- 装備品の個体管理、装備変更プレビュー、能力差の色分け表示
- 同名装備の＋1～＋3強化と、強化値を維持した売却・買い戻し
- 出血状態と、探索中の非致死ダメージを示す専用表示
- 片手杖＋魔導書と、特殊効果を持つ魔術師用両手杖
- 装備品の個体単位ロックと、倉庫・セーブをまたぐロック状態の保持
- 炎・氷・雷属性を一時付与する消費アイテムと装備・カード効果
- 毒、猛毒、出血、行動不能などの状態異常と専用治療手段

### デッキカード

- 6スロットのカードデッキ
- レベルに応じて成長するデッキコスト
- 同じカードを複数枚セット可能
- 宿屋でのデッキ編成と、町・ダンジョンでのデッキ確認
- 所持カード一覧のページ切り替え
- デッキ変更時のセット済み枚数と、編集中スロットのカード表示
- STR、INT、DEX、AGI、LUC、最大HP、最大SPなどを強化するコモンカード
- 能力値や最大HP・SPをさらに伸ばすレアカードと、複数能力を強化する上位カード
- 消費SP軽減、属性・無属性呪文耐性、状態異常耐性などの戦術カード
- 下り階段・宝箱・NPCをミニマップに表示する探索支援カード
- 黒箱から持ち帰った未鑑定カードのロット袋での鑑定
- ダンジョンで力尽きた際の持ち帰り経験値を守る「女神の恩寵」
- Canvas 2Dによるカード描画とカード入手演出
- C・R・SR・L・Zの固定レアリティコストと、排他カードの競合警告
- 探索中にHP・SPを回復するカードや、武器へ属性を付与するカード
- 長期戦や強敵との戦いで段階的・条件付きの攻防補正を得る星座カード
- 戦闘で獲得する経験値を増加させるカード
- 紫色のカード専用宝箱

### NPC援護

- 酒場で出会い、名簿へ登録して雇用できる冒険者NPC
- 最大3人まで同行し、職業ごとに異なる追撃・回復・防御・呪文援護を実行
- 同行中の到達階層に応じた10段階の成長
- 成長段階に応じて解禁されるパッシブ能力とチャージスキル
- NPC名、職業、チャージゲージを表示する常設パーティ枠
- ステータス画面で確認できるNPC援護性能
- 帰還時の雇用更新と、名簿・成長記録の継続保存

### 戦闘

- コマンド選択式のターン制戦闘
- 単体戦闘と、複数の敵から攻撃対象を選択する複数戦闘
- 戦う、スキル、防御、アイテム、オート、逃げる
- 物理攻撃、命中、会心、防御貫通
- 攻撃呪文、回復、属性相性
- 炎・氷・雷・聖・闇の属性攻撃と、敵ごとに異なる弱点・耐性
- 毒、行動阻害、能力強化・弱体化
- 毒は戦闘中の行動終了時とダンジョン歩行時にダメージを受け、HP1で停止
- 出血は戦闘中と一定歩数の探索ごとにダメージを受け、止血剤や奇蹟で治療可能
- B2F以降に出現する奈落ウサギ、さまよう亡者、ポイズンスライム
- アンデッドへの聖水と、毒への解毒剤
- 僧侶が習得する毒治療スキル「アンチドート」とアンデッド浄化スキル「エクソシズム」
- 僧侶が習得する出血治療スキル「ヘモスタシス」
- 盗賊の気配抑制、魔術師のたいまつ回復、戦士の決死の解毒など、探索にも利用できる職業スキル
- B2Fの黒扉小部屋で何度でも戦えるイベントボス「未練ある亡霊」
- 未練ある亡霊はボス扱いのアンデッドで、聖水とエクソシズムは無効
- B4Fの黒扉小部屋に潜む、序盤では非常に危険なイベントボス
- ギルド依頼と連動してB6Fの黒箱から出現する、一度限りのイベントミミック
- B9Fの赤い扉と、その先で待ち受ける関所ボス
- B19FでB20Fへの道を塞ぐ、魔法を多用する関所ボス
- B29FでB30Fへの道を塞ぐ、物理攻撃型の関所ボス
- B39FでB40Fへの道を塞ぐ、炎を操る関所ボス
- 特別な武器による攻略方法を持つ、高難度イベントボス
- AGIと行動速度補正による行動順
- 武器種ごとの攻撃特性
- 多段攻撃の個別ヒット表示と演出
- ダメージ、回復、毒ダメージのポップアップ表示
- データ駆動式の戦闘スキル演出と画面振動
- プレイヤーとNPCのチャージゲージ・チャージスキル
- 敵撃破時のフェードアウト
- 戦闘不能時は探索中の持ち帰り経験値を失い、アイテムは維持
- オート戦闘とBボタンによる中断
- 戦闘からの逃走
- 戦況に応じて敵自身が逃走する行動
- 全階層の通常戦でまれに遭遇する、高回避・高経験値の希少敵
- 戦士と盗賊が習得する、能力値に応じた通常攻撃時の即死判定
- 多段攻撃と即死判定に特化した上位武器
- 炎・氷魔法を強化する代わりに反対属性への弱点を持つ両手杖

### ギルド依頼

## Controls

### PC

| キー | 操作 |
| --- | --- |
| 矢印キー | 移動、旋回、カーソル移動 |
| `X` | Aボタン：決定、調べる |
| `Z` | Bボタン：キャンセル、メニュー |
| `L` | 装備一覧で選択中の装備をロック／解除 |

物理ゲームパッドにも対応しています。決定、キャンセル、ミニマップ、アイテムの各操作はオプション画面で割り当てを変更できます。

### Smartphone / Tablet

- 画面へ触れた位置に表示されるフローティングスティック：移動、旋回、メニュー操作
- Aボタン：決定、調べる
- Bボタン：キャンセル、メニュー
- メニューやコマンドは直接タップでも選択可能
- 町、施設、ダンジョン、戦闘中の一覧・スキル・アイテム選択に対応

## Development

ゲーム本体は、HTML、CSS、JavaScriptで構成されています。ビルド工程はなく、静的ファイルとしてGitHub Pagesへ公開しています。

ローカルで確認する場合は、リポジトリ直下で開発用サーバーを起動します。

```bash
node tools/dev-server.cjs
```

その後、以下へアクセスしてください。

```text
http://127.0.0.1:4173/
```

## Tests and Data Validation

戦闘、アイテム、依頼、宝箱罠、セーブなどにはNode.jsの自動テストがあります。

```bash
node --test tests/*.test.mjs
```

ゲームデータのID、必須項目、数値、参照先、画像パスなどは、開発用Pythonスクリプトで検証できます。

```bash
python tests/python/validate_game_data.py
```

Pythonは開発時の検証だけに使用し、ブラウザゲーム本体では使用していません。検証はGitHub Actions上でも自動実行されます。

詳しくは[`tests/python/README.md`](tests/python/README.md)を参照してください。
