# 戦闘エフェクトの再現性調査（2026-09-22）

## 結果と変更

本編とローカルジェネレーターは同じ `effect-schema.js` / `effect-engine.js` / `effect-audio.js` / `effect-stage.js` を使用する。ジェネレーター用サーバーは本編のモジュールを優先して配信し、ローカルのフォールバックも同一内容に更新した。

| 対象 | 調査時の差 | 対応 |
| --- | --- | --- |
| 敵位置 | 固定座標のみ | パーツの `anchor: "enemy"`。敵画像中心を毎フレーム取得。単体・複数敵の対象番号・変形描画の代替Canvasに対応 |
| 曲線・移動画像 | 個別の画面座標 | Canvas座標変換で始点・終点・制御点も一緒に追随 |
| 画面振動 | ジェネレーター専用処理と本編内のパーツ振動が不一致 | 共通のCSS移動処理。本編はviewportの各レイヤーを移動し、終了・中断時に元へ戻す |
| BGM・SE | 本編の正規化でaudioTracksを失う | 共通スキーマに保存し、共通Web Audio処理で開始・長さ・音量・ループ・フェード・速度を再現 |
| 画像 | 初回表示時に遅延読込 | 全画像を事前decode。`imageData`埋め込みと`imageSrc`外部素材に対応 |
| 数字 | damageのみ置換・フォント別名の差 | damage/healing置換。両アプリの同一同梱フォントをロードしてから開始 |
| 再生経路 | 固定登録した通常スキルのみ | JSON対応表で通常技とチャージ技を登録可能。未登録技は従来演出 |
| 中断 | 待機Promiseが残る | 再生中・素材準備中とも停止で待機を終了。戦闘終了時は音声・Canvas・振動を解除 |

既存JSONでanchor未指定の場合は画面基準。敵基準でも基準となる編集座標は画面中央（960×540なら480,270）。敵の大きさによる拡大縮小は行わず、位置だけを追随する。ホワイトアウト・ブラックアウト・吹雪・画面振動は画面全体の効果なので画面基準に固定する。

## 本編への登録

1. ジェネレーターの「JSONを保存」で素材を含む完全版を保存し、`data/effects/`へ置く。
2. `data/effects/battle-presentations.json`へ、スキルの`presentationId`（未指定ならスキルID）とJSONパスを追加する。
3. 例：`"call_goddess_name": "data/effects/my_goddess.json"`。
4. 命中イベントごとに再生する。複数敵への技は対象ごと、連続攻撃は各Hitごとに実ダメージを渡す。演出時間自体を通常戦闘の倍速で勝手に短縮しない。

生成プリセットをこの変更で自動的に全スキルへ割り当てることはしていない。既存のfire_ball登録を維持し、ユーザーが完成させたJSONを今後追加できる。

実装依頼プロンプトは画像・音声本体を省略するため、それだけでは素材を再現できない。プロンプト出力は`imageData`/`audioData`を空にし、`imageSrc`/`src`へ配置予定パスを指定する。実ファイルを同じ場所へ配置するか、保存JSONを使用する。外部素材パスは本編ページを基準にする。

BGMトラックは現在の本編BGMに重ねる。既存BGMを停止・差し替える指示はこのJSON形式にはない。本編のBGM/SE音量・ミュートを尊重する。テストでは無音WAVを使ってデコード・再生・停止の完了を確認し、実音の聴感比較は行っていない。

## 検証

- Nodeテスト1,520件成功。新規テストは位置変換、単体/複数敵座標、画像・音声のJSON往復、数値置換、音声タイミング・停止、読込中の中断を対象とする。
- `tests/browser/effect-parity.html`：17パーツ×2基準×5時刻=170フレーム。編集用の定義とJSON往復・本編数値置換後の定義のRGBAを比較し全画素一致。
- 同ブラウザーテストで、本編の実際の再生アダプターを使用し、動く敵DOM、埋め込み画像の事前読込、SE/BGM、終了・中断処理を確認。
- ジェネレーターUIで敵を(700,180)へ移動し、敵基準の魔法陣と操作マーカーの追随を目視確認。通常再生も実行エラーなし。
- 実機iOS/Android、全ゲーム進行からの各スキル発動、外部素材の全形式は未検証。

同一素材・同一時刻・同一論理座標・同一ブラウザー描画条件で一致を確認した。端末解像度、OS依存の明朝/ゴシック、フレームレート、ブラウザーの音声形式対応、本編背景、実ダメージ、音量設定が異なる環境で、画面・音声が無条件に100%同一になる保証ではない。
