# NPC転生連動調整（2026-10-25）

## 原因と変更

調査元HEAD: `300701e0`。作業開始時の未コミット変更なし。
NPCの固定攻撃値は成長段階10で頭打ちだが、雇用費はプレイヤーLvに比例する。
物理援護は既に敵DEFを直接差し引かない仕様であり、低火力の原因は高DEFによる減算ではなかった。
Lv197・段階10の雇用費は1人10,835G。費用・転生0回の性能は維持。

攻撃補正を転生0/1/2/3回で1/3/6/10倍とした。端数処理前に適用する。
アレクの追撃とチャージ、レベッカの連撃・開幕攻撃・チャージ、ヨハンの攻撃呪文、エリカの攻撃チャージが対象。
ステータス画面の威力も同じ補正を反映する。プレイヤーの現在の転生回数から都度計算し、NPC記録には倍率を保存しない。

段階10でのアレク追撃は38→115→231→386、レベッカ連撃は19×2→57×2→114×2→190×2。
段階による成長は引き続き有効。雇用し直しは不要。
エリカの通常回復は既に最大HPの14％（段階10）であり、その割合を増やさない。
防御・障壁・蘇生・状態異常・弱体・即死率・レベッカの現HP割合追加ダメージとボス上限500も維持。
通常アンデッドの浄化、近接無効、敵障壁の処理は維持。
