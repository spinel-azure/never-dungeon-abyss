## 調整への判断

1. 消費4倍・威力2.5倍の一律採用は見送る。育成済み戦士・盗賊の短縮幅が大きく、消費SPが4倍になる前に敵が倒れる。元から1ターンの通常敵には費用だけが増える。
2. 次の未測定候補は、消費1/2/3/4倍を残し、追加威力を1/1.25/1.5/1.75倍程度に抑えた職別比較。この新しい倍率は今回未測定で、採用値ではない。
3. 聖なる打撃・聖光は個別に見直す。通常攻撃より弱い攻撃奇蹟に消費増だけを課すのは避ける。割合回復・全快・蘇生に一律倍率を入れない。
4. マナの泉を先行して弱体化する根拠はない。水瓶座・双子座・ノヴァの軽減や再詠唱まで含め、無料状態でも強化が重なる点を評価する。
5. 三女神の難度維持を重視するなら、完全育成状態での実戦結果から強化幅を決める。
