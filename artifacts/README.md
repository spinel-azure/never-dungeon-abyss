# 検証成果物の管理

ブラウザ検証のPNGスクリーンショットはローカル確認用の一時成果物です。
`tests/browser/` の該当スクリプトで必要なときに再生成し、原則としてコミットしません。
`/artifacts/**/*.png` は `.gitignore` の対象です。既に追跡されている画像には自動適用されません。

JSONの検証結果・SHA記録・テスト入力・テストコードは保持します。
ゲーム本体の画像は `images/` にあり、この整理の対象ではありません。
報告書の画像パスは当時の検証出力先を指します。画像がない場合は対応するテストで再生成してください。

2026-10-09の整理では、ブラウザテストの出力先と確認でき、開発報告書でファイル名を個別参照していないPNGを565枚（約199.45MiB）削除しました。
個別参照のある画像、用途を確定できない画像、`item-generator-build` は保持しています。
過去のGit履歴は変更していません。作業ツリーからの削除は過去コミットの容量を直接削減しません。
