# AURORA OS — 三女神召喚ログ（単体実装）

2026-10-31。`js/aurora-summoning.js` は、ゲーム状態・アイテム所持・セーブ・戦闘・音声に依存しない独立したCanvas 2D演出。能力値変更やハッキング効果適用は一切行わない。既存 `js/aurora-boot.js` は今回変更していない。

## デバッグ

既存の `AURORA-OS-Preview.cmd` をダブルクリックし、「通常召喚ログ」または「ハッキング召喚ログ」を選択。起動演出のボタンも維持。再生終了後は同じページで何度でも再生可能。

## タイムライン

960×540、16:9。共通3行（途中に空行）を同じタイムラインで表示。通常文字32ms・空白12ms・ピリオド140ms。通常の行末500ms、空行200ms。共通の最終行後500msで分岐。

ハッキング分岐は160msの赤フラッシュと赤カーソル。WARNINGを全文表示してから200ms刻みで2回点滅させ、侵入ログを継続。SECURITY OVERRIDE : FAILEDも赤。成功行は緑で、カーソルを青緑に戻す。終了時は全文を1秒保持し、300ms暗転。

カーソルは400ms表示／400ms非表示。文字列へ追加せず、入力済み文字列の実測幅から描画位置を算出。ヘッダーと本文は分離し、本文24px太字・27px行間、全14行が下部の線より上に収まる。読みやすさのため等幅フォントを使用。文字の細い線がスマホ縮小で欠けないよう、召喚ログCanvasのみ通常の縮小補間を使用する。起動画像のピクセル補間設定は変更しない。

すべての文字と点滅・待機はrequestAnimationFrame時刻を基準に計算し、文字ごとのタイマーは作らない。

## インターフェース

```js
const presentation = createAuroraSummoning({ anchor: screenElement, pollGamepad: false });
const result = await presentation.play({ route: 'hacking' });
// result: { route: 'hacking', completed: true }
```

ルートは normal / hacking。再生開始時に確定する。途中スキップも同じルートの全文と結果を返す。中断時は completed:false。`dispose()` で中断し、`isActive()` で再生状態を取得する。

将来接続する呼び出し側はゲーム進行を停止し、`handleInput(action)` へ入力を優先転送する。外部入力を転送する場合は `pollGamepad:false` で内蔵Aボタン検出を止め、二重送信を防ぐ。再生中の終了待機を経てから戦闘開始する。ハッキング効果の一度だけの適用・保存は将来の戦闘側の責務とし、このモジュールでは行わない。

Enter/Space/Z、A、タップ対応。キーリピート・A押しっぱなし・300ms以内の連打を抑止。終了時はフレーム予約とキーボード・resize・pagehideリスナーを解放し、モーダルを削除してフォーカスを復元する。

## 検証

Nodeで共通区間、文字時間、分岐、フラッシュ、警告の2回点滅、カーソル色・周期・位置、最終色、30/60fps相当の同時刻サンプリングを検証。

ブラウザテストはPC1280px・タブレット768px・スマホ390pxで、両ルートの自然進行、全文スキップ、押しっぱなし、模擬ゲームパッド、タップ、中断、再生し直し、終了後の入力復旧を検証する。スクリーンショットはTEMPへ出力。iPhone実機・物理ゲームパッドは未確認。
