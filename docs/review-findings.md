- AGI、DEX、LUCの計算用有効値は、30以下では表示値と同じ、31以上では `30 + (表示値 - 30) * 0.5` とする。表示値60で有効値45相当となる。

- 一撃死系など、現行の上限30を前提とした特殊計算は、上限解放時に個別にバランスを確認してから適用範囲を決める。

表示仕様：

- ゲージは従来どおり30目盛りとする。
- 1～30は従来色、31～60は同じ目盛りへ金色で2周目を重ねる。
- 数値は、解禁後の主要能力およびDEFについて `42 / 60` の形式で表示する。
- 60到達時は全目盛りを金色にし、軽く発光させる。
- 未解禁の主要能力は従来どおり30上限として表示する。
- PC、iOS、Androidの各表示幅で、30目盛りが潰れず判別できることを確認する。
