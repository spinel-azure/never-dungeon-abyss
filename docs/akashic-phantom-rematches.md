# B100F エンディング後の幻影再戦（内部仕様）

2026-09-30（着手9月29日）。秘密イベントを含む開発記録。README・公開更新案内へ転載しない。

## 進行

- `ending_story_completed` が真の冒険で有効。通常の最終決戦・女王復元・杖返還・依頼034/035の討伐記録とは別ID。
- 毎回、従来どおり十の守護者を全員倒す。強さは変更せず、クリア後は初回討伐フラグが不足する古いセーブも経験値0。
- その後 `erzdaemonin_phantom_b100f` → `amayenak_phantom_b100f` の連戦。報酬は経験値0・固有ドロップなし。通常のカード由来の追加効果は既存処理に従う。
- 討伐済みリストは既存の `b100GauntletDefeatedBossIds` に保存し、その冒険中の再読み込みでは維持。次の入場でリセットする。永続的な初回ボス討伐フラグでは幻影を省略しない。
- エルツ撃破直後はマップの最終ボスをアマイェナク幻影へ更新して保存。連戦の間に保存・終了した場合、ボスマス上のロードから第二戦を再開し、背後の転送陣へのすり抜けを防ぐ。古い連戦タイマーは、別戦闘・別地点・討伐後へ干渉しない。
- 幻影アマイェナクを倒すと `achievement_amayenak_phantom_defeated`。実績名「アマイェナクの幻影を倒した」、未解放ヒント「？？？？？？――因果記録庫暴走」。女王復元、エンディング、真実の杖の再配布は行わない。
- 通常決戦と同じく逃走率0。勝利後は既存の入口行き転送陣を使える。敗北時は既存の寺院への帰還処理。

## 強さ

| 項目 | エルツ幻影 | アマイェナク幻影 |
|---|---:|---:|
| 最大HP | 56,000（通常の2倍） | 54,000（通常の1.5倍） |
| 通常の攻撃・呪文ダメージ補正 | 1.2倍 | 1.2倍 |
| DEF・基礎能力・属性耐性 | 通常版を維持 | 通常版を維持 |
| 猛毒の1tick上限 | 280 | 270 |
| 死毒の1tick上限 | 560 | 540 |

猛毒・死毒はレーヴェンケーニギンと同じ抵抗値50、同じ最大HP比率（0.5%・1%）で制限する。上限率は `LION_CONFIG.dotRates` を参照。毒・出血など、指定外の耐性は通常版を維持する。

### 魅了

- エルツ幻影の追加行動「魅惑の眼差し」。闇呪文威力25、魅了の基礎付与率40%。既存の能力差・耐性・付与率上下限を適用する。
- 通常の状態異常（`charm`）。3回のプレイヤー行動機会にわたり、防御・逃走失敗・見とれる待機を各1/3で自動選択。ボスの逃走率0を迂回しない。
- 効果中の再付与で残り時間を延長しない。先に敵が魅了を付与した場合も、その後の選択済み攻撃を実行せず、事前消費SPを戻す。アイテムを勝手に消費しない。
- キルケの護符は、従来どおり上下限処理後に付与確率を半減。ムーサの冠の `temptationResistance: 1` は完全無効を先に適用。説明に「魅了完全耐性」を追加。
- 名前と職業直後の♥をピンク色で表示する。毒・出血の名前色より優先。解除・戦闘終了時に消す。キーボード、タッチ、ゲームパッドの共通入力をロックし、タイマーで戦闘を進める。

### アポカリプスと因果律改変

- HP65%以下で一度だけ予告し、次の敵行動で既存 `apocalypse` JSONを再生。呪文威力330、闇属性、命中保証。
- 通常の属性耐性等を反映して1.2倍にした後、単発ダメージを最大HPの60%以下（端数切り捨て）へ制限。既存の無敵・障壁・NPC防壁はその後も有効。現在HPが減っている場合の生存は保証しない。
- Lv197、初期装備・追加カードなし、乱数0.5で予告後に防御した比較：戦士999HP→414ダメージ、盗賊850→414、魔術師650→390、僧侶750→414。これは生存確認用の固定条件であり、全装備・全ビルドの攻略バランス保証ではない。
- 初めてHP0になると「因果律改変」で27,000HPへ復活。通常攻撃・継続ダメージ・NPC攻撃を対象に勝利確定前で処理し、最初の消滅演出を抑止。二度目のHP0で決着。アポカリプスの使用済み状態は復活で戻さない。
- 戦闘を開始し直したときのみ、復活・予告の一回制限をリセットする。

## 表示

- 入口と最終警告は `NPC_01c.avif` と指定台詞。通常3行枠の実寸でページ分割。
- 走査線、横ずれ、ちらつき、会話後に縦方向へ潰れて消える投影演出。ノイズ**音**は追加していない。
- 最終玄室は提供された `dungeon_event_00b.avif` と `NPC_event_19.avif`、襲撃時は `NPC_event_20.avif`。人物をシルエット＋光彩で表示。
- 戦闘背景は同じ背景に80%黒、Canvasの魔力粒子と亀裂。戦闘を閉じる際にCanvas・RAFを破棄。
- 軽減モーションでは投影の横ずれ・ちらつき・潰れと魔力の移動を止める。通常の透過フェードは残す。
- 新しい幻影画面だけ、短いスマートフォン枠でも名前とHPが見切れない空間を確保。
