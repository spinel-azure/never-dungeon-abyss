# ヴァッサーマンフラウ実装報告

## 導線・保存・実績

B18Fの固定特殊部屋へ配置。紫扉に所持Zカード条件はなく、入室確認と戦闘前のBキャンセルに対応。虫部屋・紫箱への置換対象から除外した。既に生成された保存済みフロアを強制再生成せず、進行を維持する。

逃走は100％成功し、再挑戦ではHP・障壁を初期化する。完全撃破は既存イベントボスの報酬・フラグ経路を使用し、Z「アクエリアス」1枚、EXP50,000を付与。討伐後は再戦・重複報酬を防ぐ。

実績名は「ヴァッサーマンフラウを撃破した」、ヒントは「？？？？？？――水瓶座の守護者」。討伐フラグから判定する。

Lv85／HP4,000／ATK24／DEF30／STR18／INT30／AGI24／DEX27／LUC25／EXP50,000。ATK24は今回の仮設定。

行動重みは、水瓶の一撃（物理1Hit・倍率1）30、水魔の奔流（無属性魔法・基礎威力32）40、魔力吸収30。

氷0.5倍、炎・雷・光・闇・無属性魔法1倍。即死無効、毒・猛毒・出血系耐性50ポイント、行動不能耐性80ポイント。定義ファイルで調整できる。最終バランスの実プレイ調整は未実施。

画像は `images/background/dungeon_event_18.avif` と `images/bosses/boss_26.avif`。BGMは既存イベントボス曲。討伐後は同じ部屋画像に「部屋は静まり返り、水瓶には澄んだ水がたたえられている。」という仮文章を表示する。

## 障壁・魔力吸収

敵個体に専用の現在値・最大値1000を保持し、プレイヤーの魔力障壁とは分離。HP直下へ「♒ 現在値 / 1000」を表示する。

複数Hitは一つの攻撃行動として扱う。行動開始時に障壁があれば途中で破壊されても残りHitはHPへ流さない。通常攻撃・呪文・投擲・NPC攻撃へ適用し、反射・継続ダメージも障壁を通す。障壁で防いだダメージからHP被弾依存効果を発生させない。

障壁の被弾では既存SE登録 `crystalObstacleBreak`（boon.wav）を行動ごとに1回使用し、通常HP被弾SEを抑制する。青い半透明の障壁は既存Canvas前面レイヤーに描き、ボス画像を加工しない。弱く脈動し、0で消え、回復で再表示する。

魔力吸収は現在SPの25％を切り上げて奪い、実際に吸収した量の2倍を障壁へ回復する。上限1000。0からも再展開できる。最大値へ回復した遷移フックを追加したが、将来の「水瓶の満潮」は未実装。
