# Gold boss Candidate 1: Zカード6枚検証

ボス能力・本番コードは変更していない。実戦エンジンによる自動試験であり、PC・iPhoneの手動実機確認ではない。

## 条件

- プレイヤーLv200。Zカード6枚はコスト48で、通常ルール上Lv197以上が必要。地図LvとプレイヤーLvは別。
- 地図Lv60 / 80 / 100、4職、NPCなし／あり、3デッキ、各50乱数seed。合計3,600戦。
- B90既存テスト装備+3、開始時HP/SP全快、回復薬40個。NPCはアレク／レベッカ／エリカ、成長段階9、初期charge 0。
- 習得済みcharge・ultimateを使用。リーオー装備時はcharge間に通常攻撃を使用。
- 比較は既存標準デッキ、Z6枚、スコルピオを別Zカードへ交換した6枚。装備・戦術の網羅的最適化ではない。

## 選択デッキ

|職|6枚|
|---|---|
|戦士|サジタリウス、リーオー、リーブラ、カプリコーン、スコルピオ、トーラス|
|盗賊|サジタリウス、ジェミニ、リーブラ、カプリコーン、スコルピオ、パイシーズ|
|魔術師|アクエリアス、ジェミニ、リーブラ、カプリコーン、スコルピオ、ヴァルゴ|
|僧侶|アクエリアス、ジェミニ、リーブラ、カプリコーン、スコルピオ、トーラス|

物理職は防御無視と攻撃強化、魔法職はSP障壁と連続発動、共通で対ボス補正・長期戦補正・死毒を選択した。スコルピオなし比較では盗賊はトーラス、他職はパイシーズに交換。

## 結果

Z6枚は全地図Lv・全職・NPC有無で各50戦全勝（計1,200勝）。

地図Lv100、平均勝利ターン：

|職|Z6ソロ|Z6＋NPC|死毒なしZ6ソロ|死毒なしZ6＋NPC|
|---|---:|---:|---:|---:|
|戦士|26.52|21.48|64.70|41.96|
|盗賊|18.82|16.36|58.30|43.76|
|魔術師|24.08|22.64|180.28|95.90|
|僧侶|24.90|22.86|勝利なし（全50戦200ターン上限）|172.28|

地図Lv100のZ6ソロ最大ターンは戦士65、盗賊38、魔術師35、僧侶40。平均回復薬使用回数は4.72 / 0.94 / 0 / 0。

同じプレイヤーLv200の標準デッキでは、ソロは全職勝利なし。NPCありでは全職50勝だが平均84.86～152.08ターン。

## 判断

Z6枚を前提とする特殊高難度ボスとして、現行Candidate 1でも討伐は成立する。以前の低プレイヤーLv・標準デッキの結果だけを根拠にHPを大幅削減する判断は保留する。

一方、スコルピオによる最大HP5%の死毒への依存が大きい。Lv100ソロで死毒の平均ダメージは戦士19,810.82、盗賊19,687.64、魔術師29,940.96、僧侶30,651（ボスHP32,000）。特に後二職では直接攻撃の強さより死毒が討伐時間を決めている。カード自由度を求めるなら別途調整検討が必要。

主要能力30capと設定値の不一致自体は今回も残る。Z6で勝てることは、その設計上の不一致が解消したという意味ではない。
