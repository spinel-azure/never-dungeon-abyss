# 地図管理の調査情報

2026-10-25実装。

- 地図探索V2の管理画面にエリア名・環境効果を登録時から表示。
- B1F～B3Fごとの保存済み `surveyedMasks` を使用し、その階が100マス踏破済みの場合だけ敵名と出現割合を表示。過去の記録にも追加の移行処理なしで適用。
- `normalizeSpecialMaps` が復元する `cleared`／`bossClears` に基づき、討伐後だけボス名を表示。踏破完了だけではボス名を公開しない。
- 敵分布は探索と同じ `generateRegisteredSpecialMap`、`generateV2EcologyCandidate2` を使用。敵名は戦闘定義から取得。割合はweight/100、通常遭遇時の敵選択割合であり遭遇発生率ではない。
- 通常テーマ、特殊テーマ指定、黄金郷の固定分布に対応。Lv99以下の特殊テーマでボス名は公開しない。V1／旧地図の管理画面は維持。
- 未解放階は敵情報を表示データに含めない。画面を開くだけで踏破・討伐・保存データを変更しない。
- PCは3列、680px以下は1列。情報領域を縦スクロール可能にして操作ボタンを別の行へ残す。既存の共有・コピー・お気に入り・削除・戻る導線を維持。
