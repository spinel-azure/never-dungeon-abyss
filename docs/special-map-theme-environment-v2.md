## 環境効果

| 地図テーマ | 奈落と共有するルール |
|---|---|
| red／灼熱 | 実際の歩行完了ごとにHP1減少。HP1で止まり、死亡しない。防火靴で無効。 |
| blue／極寒 | 実際の歩行完了ごとにHP1減少。HP1で止まり、死亡しない。防寒靴で無効。 |
| crystal／結晶 | 3歩ごとにSP1減少。SP0で止まる。 |
| black／漆黒 | リヒトブリンガー未所持ならたいまつ燃料0固定、補充アイテム・補充スキルは不使用扱い（消費なし）。所持時は補充可能でlight配色。 |

`getFireFloorStepDamage`、`getColdFloorStepDamage`、`applyCrystalFloorSpStep`、`getNonlethalPoisonDamage`、既存の装備／貴重品判定を共有。
通常奈落の深度を読み替える代わりに、テーマから既存区域のルールを選ぶ。地図Lvには依存しない。
装備ID方式・装備インスタンス方式の両方を既存関数で判定する。
前進／後退・自動歩行の移動完了で一度だけ実行。旋回、壁への衝突、開扉、入場配置、階段転送では歩数を増やさない。階段・宝箱マスへの通常の一歩は対象。
結晶カウンターはV2セッション内で管理し、階段移動でも維持。再入場は0から。通常奈落の `character.crystalFloorStepCount` は変更しない。
HP/SP減少表示は既存の歩行ダメージ表示を使用。

漆黒でも永続たいまつカードの「燃料によらない有効照明」は通常奈落と同様に維持する（燃料の補充制限は別）。
暗闇では通常敵を不意打ち・敵名隠蔽とし、牡羊カード装備なら不意打ちを防ぐ。固定ボスに不意打ちは付けない。
リヒトブリンガー所持は補充制限を解除するが、燃料を自動補充する処理は追加しない。

今回は地形・配置を変えずに共有できる上記4種を接続。
流砂・激流・火柱・氷塊・植物・結晶塊・闇球など、設置座標／経路／除去状態を伴うギミックは未移植。特殊4テーマへの独自環境効果は追加しない。
一般の毒・出血・NPC探索回復など、テーマ固有でない歩行効果の仕様拡張も本変更の対象外。

## トレリーレンの討伐報酬受領

探検家テントで受領保存が成功してから、既存 `importantItem` ジングルを再生し、終了後に赤錆びた鍵と共通のITEM GETポップアップを表示。
絵は `images/item-compendium/unidentified_map.avif`、文言は「未鑑定地図」を手に入れた！。
既存アイテム入手表示に任意画像ソースを渡せるよう拡張した。架空の通常アイテムをインベントリや図鑑へ登録することはない。

演出は約3.4秒。ジングル／ポップアップの間はテントの決定・戻る・マウス・タッチ操作を抑止。
上限3枚で満杯、保存失敗など、受領できなかった場合は演出しない。再受領・再付与もしない。
画面終了時はAbortSignalにより遅れてポップアップが出るのを防ぎ、表示中なら隠す。
音声ミュート／音源が再生できない場合もポップアップへ進める。音声オプションは既存設定に従う。
