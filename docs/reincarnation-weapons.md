# 転生コモン武器・最終猫武器（内部資料）

2026-10-21。公開案内/READMEへ秘密詳細を転記しない。末尾の「入手接続確定」が最新。以前の未接続記述は武器実装時点の記録。

## 実装

- data/reincarnation-weapons.js に12コモン×4段階、4最終ユニーク。依頼の数値どおり。武器種/職業/必要転生を既存の装備確定と保存正規化で検査。共通の付与/鑑定/ロット袋精算/倉庫定義を利用。
- HP/SP追加はfloor(getLevelGrowthによる基礎最大値×装備率)。カードの最大値倍率適用後に加算。着脱時は現在値維持、低下時のみクランプ。ウィングギフトの既存最大HP減算はその後に適用。
- コモン短剣は0.6×2、メイスは25%貫通。最終短剣は専用武器種0.5×5。既存の命中/会心/貫通上限/スキル回数判定を利用。
- 回復奇蹟/攻撃呪文/SP軽減/再詠唱は既存補正へ接続。攻撃奇蹟はmiracle分類の物理holy_strikeと呪文holy_light等を対象。
- レガリア食いしばりは直接攻撃・バリア後、既存致死回避/双魚復活前。多段の残ヒットは有効。使用済みはplayer.weaponEndureUsedで保存。新戦闘でのみリセット。無敵/DOT/即死/探索ダメージ対象外。
- 武器は防具セット構成部位に含めない。魔術師は両手杖で左手なしでも頭/胴/足セット成立。詳細には武器効果を表示、セット効果の秘密表示は維持。
- 黒箱は現状、各階1個の固定配置と未開封表示のみ。報酬は未設定。既存の赤箱報酬・地形・箱数・配置・SEED処理は一切変更していない。
- コモン価格未設定、最終猫は既存ユニーク形式のsellPrice:0（現在売却候補外）。これは入手仕様の承認を意味しない。廃棄規則を新設していない。入手接続時に売却/廃棄方針を確定する。
