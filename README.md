# NEVER DUNGEON : ABYSS

> THE MISSING QUEEN AND THE MYSTERIOUS CAT

![NEVER DUNGEON : ABYSS](images/screenshots/nda_ss_01.avif)

**NEVER DUNGEON : ABYSS（NDA）** は、ランダム生成される疑似3Dダンジョンを探索するブラウザRPGです。

[Never Dungeon Engine Ver.1.0](https://github.com/spinel-azure/never-dungeon-engine)をベースに、戦闘、職業、成長、装備、町、シナリオなどのRPG要素を開発しています。

現在のバージョンは **MVP1.0** です。

## Play

ブラウザからプレイできます。

**https://spinel-azure.github.io/never-dungeon-abyss/**

PC、スマートフォン、タブレットに対応しています。開発中のため、仕様やセーブデータ形式が変更される場合があります。

## Current Features

### ダンジョン探索

- 10×10マスのランダムダンジョン生成
- 全セルへの到達保証
- Canvas 2Dによる疑似3Dレイキャスト描画
- 扉、階段、階層移動
- フロアごとの壁・床テーマ
- 霧、暗闇、たいまつ
- 気配ゲージ
- コンパス、ミニマップ
- NPCイベントとタイプライター会話
- 赤・黒・金の宝箱とThree.jsによる開閉演出
- 石つぶて、石弓、毒針の宝箱罠と解除・回避判定
- 罠解除結果のポップアップ演出
- 踏破済み経路を使ったオート帰還
- 階層移動時のSE、暗転、フェード演出
- エンカウント時のズーム・フェード演出

### 町

- 町全景から施設を選択する拠点画面
- 前景の背後を雲が流れる多層背景
- 施設ごとの背景、NPC立ち絵、会話
- NPC立ち絵の呼吸アニメーション
- 宿屋、ギルド、寺院、商店、図書館、ダンジョン入口
- ギルドでのキャラクター登録
- 宿屋でのHP・SP全回復
- 敵撃破時の持ち帰り経験値と宿屋での経験値精算
- Lv197までの連続レベルアップと職業別HP・SP成長
- 戦闘不能時の寺院での蘇生
- 寺院での寄進と、商店での回復・探索アイテム購入
- 最大3件まで同時受注できるギルド依頼
- B1Fの討伐・踏破依頼と、達成・追加報酬演出
- ダンジョン入口と転送施設の準備画面

一部の施設サービスは現在開発中です。

### キャラクター

以下の4職業から選択できます。

| 職業 | 特徴 |
| --- | --- |
| 戦士 / WARRIOR | 高いHP・STR・DEFを持つ物理戦闘型 |
| 盗賊 / THIEF | 高いAGI・DEXと短剣の2回攻撃を活かす技巧型 |
| 僧侶 / PRIEST | 回復、守護、防御貫通攻撃を扱う安定型 |
| 魔法使い / MAGE | 高いINTと属性呪文を扱う魔法戦闘型 |

- STR / INT / AGI / DEX / LUCによる能力値
- HP / SP / DEF
- 職業別の初期能力値、初期装備、初期スキル
- 装備補正を含むステータス表示
- 詳細ステータス表示
- 装備・カードによる最大HP・SP補正の色分け
- 毒状態と歩行毒ダメージの専用表示

### デッキカード

- 6スロットのカードデッキ
- レベルに応じて成長するデッキコスト
- 同じカードを複数枚セット可能
- 宿屋でのデッキ編成と、町・ダンジョンでのデッキ確認
- 所持カード一覧のページ切り替え
- STR、INT、LUC、最大HP、最大SPを強化するコモンカード
- ダンジョンで力尽きた際の持ち帰り経験値を守る「女神の恩寵」
- Canvas 2Dによるカード描画とカード入手演出

### 戦闘

- コマンド選択式のターン制戦闘
- 戦う、スキル、防御、アイテム、オート、逃げる
- 物理攻撃、命中、会心、防御貫通
- 攻撃呪文、回復、属性相性
- 毒、行動阻害、能力強化・弱体化
- 毒は戦闘中の行動終了時とダンジョン歩行時にダメージを受け、HP1で停止
- B2F以降に出現する奈落ウサギ、さまよう亡者、ポイズンスライム
- アンデッドへの聖水と、毒への解毒剤
- AGIと行動速度補正による行動順
- 武器種ごとの攻撃特性
- 多段攻撃の個別ヒット表示と演出
- ダメージ、回復、毒ダメージのポップアップ表示
- 敵撃破時のフェードアウト
- 戦闘不能時は探索中の持ち帰り経験値を失い、アイテムは維持
- オート戦闘とBボタンによる中断
- 戦闘からの逃走

### ギルド依頼

- 依頼001「奈落ネズミ退治」：B1Fで奈落ネズミを15匹討伐
- 依頼002「スライム退治」：B1Fで洞窟スライムを15匹討伐
- 依頼003「迷宮地下1階調査」：帰還せずにB1Fの100マスを踏破
- 討伐依頼と踏破依頼の同時進行
- 依頼ごとのデッキカード報酬と追加報酬200G
- 3依頼すべての達成によるB2F解放とイベントカード入手

### セーブと設定

- キャラクターデータの作成と継続プレイ
- 常時更新されるオートセーブ1枠
- 町で選択できる任意セーブ3枠
- ダンジョン内ではオートセーブのみ使用可能
- タイトル画面のCONTINUE、LOAD GAME、NEW GAME
- キャラクター名、レベル、保存日時を表示するロード画面
- 全セーブ枠のJSONエクスポートと手動インポート
- ダンジョン滞在中のフロア・マップ状態保存
- LocalStorageによる設定保存
- SE音量、画面の揺れ、たいまつの揺らぎ
- NPC会話のタイプライター表示と速度設定

## Controls

### PC

| キー | 操作 |

- バーチャルスティック：移動、旋回

- メニューやコマンドは直接タップでも選択可能

## Development

ゲーム本体は、HTML、CSS、JavaScriptで構成されています。ビルド工程はなく、静的ファイルとしてGitHub Pagesへ公開しています。

ローカルで確認する場合は、リポジトリ直下で開発用サーバーを起動します。

```bash
node tools/dev-server.cjs
```

その後、以下へアクセスしてください。

```text
http://127.0.0.1:4173/
```

## Tests and Data Validation

戦闘、アイテム、依頼、宝箱罠、セーブなどにはNode.jsの自動テストがあります。

```bash
node --test
```

ゲームデータのID、必須項目、数値、参照先、画像パスなどは、開発用Pythonスクリプトで検証できます。

```bash
python tests/python/validate_game_data.py
```

Pythonは開発時の検証だけに使用し、ブラウザゲーム本体では使用していません。検証はGitHub Actions上でも自動実行されます。

詳しくは[`tests/python/README.md`](tests/python/README.md)を参照してください。
