# レーヴェンケーニギン 公開前バランス検証（2026-09-19）

## 結論

「王者の隙」を本体へ仮倍率 **3／4／5** で実装。HP100,000、DEF60／45／30、女王の与ダメージ1／2／3、第三形態の自傷1000（HP1止まり）、毒系・出血上限、予約AI、画像・報酬・逃走率は維持した。

**魔術師型は目標達成。今回の戦士構成・操作方針では100～180ターン目標は未達。** 3／4／5の魔術師は100勝、108～173ターン（平均136.43）。死毒なし戦士は平均518.73／342.38／282.72ターン。3／5／6でも物理側の不足を解消できなかった。

推奨は **3／4／5を暫定維持し、最終決定は保留**。3／5／6への引上げは魔術師をさらに短縮する一方、物理の第一形態の長さを解決しない。今回の指定装備の戦士はSTR30・武器攻撃42が基礎で、通常攻撃を倍率だけで強くする効果は限られる。一方、魔術師はINT28×10の隕石を複製し、魔力増幅や隙へ合わせられる。次の相談では物理技／武器による直接火力と、第一形態の攻撃機会を検討したい。未承認の数値変更は行っていない。

B1FはleoPreparationのまま、LEO_EVENT_RELEASED=false。正式開放・コミット・pushなし。

## 実装方式

- combat/loewenkoenigin.js：女王専用の戦闘中フラグlionOpening、生成・行動開始時倍率取得・行動終了時解除・戦闘終了時消去。
- data/loewenkoenigin.js：openingMultipliers=[3,4,5]を専用設定へ追加。
- combat/battle-engine.js：王断のダメージ・反撃処理後に隙を生成。咆哮、行動不能、未実行の予約には生成しない。王断がミスでも振り抜いているため生成する。女王が反撃で死亡済みなら生成しない。
- プレイヤーの通常攻撃／物理攻撃スキル／攻撃呪文／攻撃奇蹟（actionTypeがphysicalAttackまたはspell）を行動シーケンス開始時に認定。元攻撃と複製・武器再攻撃に同じ倍率を渡す。全体攻撃では女王へのHitだけに適用。
- 倍率は行動開始時の形態で固定。多段中に第二・第三形態になっても、その行動中に倍率は変わらない。
- **次に実際に実行するプレイヤー行動終了で失効**。直接攻撃ならミスでも使用、回復・防御・アイテム・待機・強化なら未使用のまま失効。キャンセル／不正コマンド／行動不能は行動実行にならず保持。行動可能になった後の最初の実行行動までで、チャージや回復を繰り返して保存できない。
- DOT4種、NPC通常／チャージ、キャンサー、女王自傷、投擲アイテムは別経路で倍率を受けない。現行エンジンにはプレイヤーの独立した遅延ダメージ予約経路は見当たらず、汎用HP減算側には倍率を入れていない。将来の遅延処理にも自動適用されない。
- 逃走・勝敗確定・新規戦闘生成時に消去。キャラクターの保存値へ追加していない。
- js/battle.js／css/battle.css：コマンド選択時、女王のHPゲージの下に金色の「王者の隙」を表示。戦闘演出中の確定後状態の先出しを避けるため表示を待つ。

## カードとの計算順

サジタリウスの命中・DEF無視・属性耐性処理 → 既存の基礎ダメージ／軽減 → リーブラ・カプリコーン・エアリーズ・魔力増幅等とジェミニ0.5を既存順序で反映し切り捨て → **隙倍率** → 既存の障壁・実HP減算。

ジェミニは「元の最終ダメージの半分」ではなく、既存どおり攻撃式を再実行して0.5倍する。通常技なら元攻撃×Mと複製×0.5×M（端数処理あり）。複製にMを再帰的に二重適用しない。チャージ技は既存仕様どおりジェミニ複製対象外。

エアリーズ併用は元攻撃が2×M、複製は0.5×M。第一形態なら6倍と1.5倍相当、第三形態なら10倍と2.5倍相当。エアリーズの2倍は複製へ継承しない。整数切り捨てにより1未満の差はあり得る。

リーブラの実装は **ボス OR プレイヤーより高レベル**。Lv125の女王はisBoss=trueなのでLv197にも与ダメージ1.3、被ダメージ0.7が適用される。説明との差異なし。両方向を実ダメージ比較テストで確認。

カプリコーンの最大3段階（与ダメージ+30%、被ダメージ-30%）も維持。サジタリウス装備時にDEFを極端に上げても物理ダメージが変わらないこと、そこへ隙が乗ることを確認。

操作は公開情報（HP・SP・チャージ・予約・隙）だけを使用。王断予告中は防御、HP40%未満で回復。C/Dはパワーストライクでチャージを進め、隙にドラッヘン・ファング（1戦1回）／ファルケン・シュニットを使用。奥義SP100を確保し、チャージ満タン時は隙まで通常攻撃。Eは炎よ燃やせでSP節約、隙に隕石・ツングースカ・アポカリプス、魔力増幅を使用。アクエリアス破壊後は正規SPを消費。アルハイルミッテルが使用可能ならSP不足時にも使う。

これはこの操作方針での比較であり、全ての装備・カード・最適手順を総当たりした勝率ではない。600ターンで打ち切らず上限1000ターンまで追ったことで、倍率なしBも641～694ターンで勝てると確認できた。「600ターンで倒せない」と「撃破不能」は区別する。
