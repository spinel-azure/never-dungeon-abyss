# 転生前後と低レベルでのスキル調整比較

2026-10-28、HEAD 5faf7f3b。本番コードは変更していない。共通追加威力1/1.25/1.5/1.75倍と前回の僧侶個別案を、転生0〜2回の育成完了時、転生0の序盤、転生1〜3回直後で比較した。

結論：転生0のLv1は変更なし、Lv10も小さい変化。僧侶が最初から突然強くなる結果ではない。ただし聖光を覚えるLv34で能力を育てている場合は大きく強化される。一律INT係数3より、転生に応じINT係数1.5/2/2.5/3とする追加候補が序盤の抑制に向く。共通倍率には低転生で三女神へ勝ちやすくする影響があり、僧侶の序盤とは別の採用判断が必要。

## 案

- 現行：変更なし。
- 前回候補：有料攻撃技のSP原価を転生回数に応じ1/2/3/4倍、追加威力1/1.25/1.5/1.75倍。聖なる打撃は通常物理と同じレベル・転生補正を追加。聖光のINT係数を0.5→3。回復・補助・通常攻撃・チャージ・奥義は変更しない。
- 追加候補：聖光のINT係数だけを転生0/1/2/3回で1.5/2/2.5/3にする。共通倍率・消費原価・聖なる打撃は前回候補と同じ。初回はLv34の僧侶5条件を追加測定。その後、転生1/2回Lv197の三女神戦を追加測定した（末尾の追記）。

聖光の習得はLv34。Lv1/10/33では使わない。候補の聖なる打撃の追加補正はLv1・転生0なら1なので、そこでは現行と同じ。

## キャラクター条件

|---|---|---|---|

基本Zカードは射手座・天秤座・山羊座・牡牛座・魚座・蟹座。DEFは正規計算。前世の基礎能力上限まで刻印を育てた想定なので、転生後には装備加算分が以前の実効上限を超える場合がある。新しい上限まで一律に育て直した状態ではない。

freshのLv33/34でも防具を更新しないのは、弱い装備・低いINTを固定する対照条件。平均的な進行装備ではない。trained-earlyは序盤から刻印で能力30まで育てた上側の条件。実プレイヤーの平均成長を主張しない。

## 戦闘条件

- 通常攻撃主体と、各職の習得済み攻撃技主体を分ける。戦士は強打、盗賊はLv22前が素早い一撃・以後疾風連刃、魔術師は火炎基本呪文。僧侶は聖なる打撃と、Lv34以降の聖光を別々に測定。
- SP不足は通常攻撃へ。未習得技を使用しない。Lv55以降の攻撃チャージ・Lv80奥義は習得済みで充填できた時だけ使用。低レベルの補助チャージ、回復奇蹟、支援魔法は使わない。
- 三女神の予告は防御。HP60％未満で薬、ゼレーナ回復準備中は35％。complete/restartだけ強回復薬（大）30個。fresh/trained-earlyは薬なし。NPC・デバイスなし。
- 各戦HP/SP全快、チャージ0、30seed、500ターン打切り。SPは実支払い累積。敵からのSP減少は含めない。
- 新規Lv1：奈落ネズミ・洞窟スライム・さまよう亡者。Lv10：奈落ネズミ・ポイズンスライム・ヴァイパー。Lv33/34：ヴァイパー・バンシー・火トカゲ。
- restart：奈落ネズミ・バンシー・アメジストゴーレム。育成済み装備を引き継いで浅層・深層へ戻る比較であり、敵をプレイヤーLvまで弱くしない。
- complete：アメジストゴーレム・ゼンゼンマン。転生1/2はLv100三女神も追加。転生0は挑戦条件未達のため三女神を対象にしない。
- 主要比較は459行×30seed×2案＝27,540戦、単発威力144行×30seed×2案＝8,640コマンド。追加候補は1,350戦・450単発コマンド。合計28,890戦と9,090単発コマンド。
- 単発威力はDEF0・属性耐性なし・種族弱点なしの中立標的を、毎回新品の戦闘で攻撃した30seed平均。敵能力は1、HP100万。実敵との勝率・ターン数とは区別する。
- 表の平均ターン/SPは勝利戦のみ。勝数が異なる行は母集団も異なる。同seedでも行動が変われば乱数消費順は変わる。回復・解毒やNPCなしの固定攻撃方針なので、序盤そのものの難度評価ではない。

## 僧侶の序盤の評価

転生0・Lv1の聖なる打撃は中立標的に8.57ダメージで完全一致。Lv10は8.57→8.83。実敵のネズミ・ポイズンスライムでも撃破ターンは変わらない。

Lv34・INT6では聖光の単発平均が24.47→39.40。バンシーは24勝→30勝、平均4.00→3.10ターン。ただし勝利平均の母集団が異なる。バンシーには聖属性弱点1.5倍に加え、聖光の対アンデッド1.5倍がある。

Lv34・能力30育成済みでは聖光が35.67→108.67となる。バンシーは2.30→1ターン、火トカゲは5.12→2ターン。能力育成が進んでいれば一律INT係数3は強い。

追加候補のINT係数1.5なら、育成済みLv34の火トカゲは3ターン・36SP（前回候補2ターン・24SP）。バンシーは引き続き1ターン・12SP。対アンデッドの得意分野を残して、無条件の威力を少し抑えられる。INT6のバンシーも30勝・3.13ターンで、前回候補の3.10とほぼ同じ。

## 転生直後の評価

聖なる打撃は強化されるが、引き継いだ装備の通常攻撃も既に強い。中立標的で、転生1回Lv1の通常攻撃127.83に対し候補134.57、転生2回では336.23に対し411.50、転生3回では651.20に対し996.30。SPは8/12/16。

ネズミは現行でも通常攻撃1ターンなので、候補でさらに戦闘が短くなることはない。アメジストゴーレムには技を使う差が出る。今回の完全育成継承条件では、聖なる打撃を再び使える攻撃手段にする効果と判断する。全員の転生直後が同じ装備・能力という意味ではない。

## 三女神への影響

転生1回の盗賊はゼレーナ0→24勝／30戦。転生2回の戦士はルミナ1→30勝。共通威力が小さく見えても、回復を阻止できるか・薬が尽きる前に倒せるかを変える。

僧侶は転生1/2回とも、今回の攻撃技主体では三女神0勝のまま。これは倒せない証明ではなく、回復奇蹟なしの固定操作での結果。僧侶の序盤過剰強化よりも、他職が早い転生段階で三女神に勝ちやすくなる点が採用判断上の重要な変化。

推奨：聖なる打撃は候補を維持、聖光は一律INT3ではなく1.5/2/2.5/3を次の候補とする。転生3回の前回測定値は維持される。共通倍率は低転生の三女神勝率の変化も踏まえて判断し、本番適用は保留する。追加候補の低転生Lv197三女神戦は末尾の追記を参照。連続探索は未測定。
