## 実装

- B76Fの固定イベント部屋。異なるZカード3種類の所持が条件。装備・消費不要。既存のアクセス判定、挑戦確認、A/Bでの入室演出、戦闘開始、勝利報酬を利用。
- 個体ID `tiefstrom_b76f` / `tiefstrom_b76f_b`。同時二体、個別HP・状態・対象選択。逃亡率100％、再挑戦は全快。討伐後再戦不可。初回完全勝利のみパイシーズ1枚、EXP合計50,000。途中逃亡では勝利処理へ進まない。
- `boss_25.avif`二体、`dungeon_event_16.avif`、BGM `battle-of-galfer.mp3`。戦闘HPバーと準備表示、スマホの敵タップ選択を確認。
- 近接物理攻撃を命中判定より前に拒否。属性付与・必中・DEF無視で突破不可。近接の「聖なる打撃」も対象外。遠隔の聖光・攻撃呪文・投擲は有効。追撃・追加異常は届かない攻撃から発生しない。
- NPCのアレク／レベッカの近接とエリカの聖なる打撃は届かない。ヨハンの攻撃呪文、エリカの回復・治療は維持。NPCダメージ経路に射程情報を渡し、追加弱体や即死も阻止。
- 継続ダメージと、キャンサー等の間接反撃には射程制限を追加しない。パイシーズの復活・無敵処理は維持。
- 大渦は抽選時に予約。準備・発射ターンは他個体の準備を禁止し、二体生存時は交互担当。行動不能では保留、死亡では予約解放。一体時も発射後に別行動を挟む。防御は大渦に有効。
- 片方撃破後は残りの武器ATKを1.2倍として物理計算。STR部分や呪文には掛けない。重複・二体同時撃破時の怒りなし。
