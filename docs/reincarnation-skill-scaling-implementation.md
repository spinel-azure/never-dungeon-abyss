# 転生による攻撃技強化 実装記録

2026-10-28。ユーザー採用指示に基づき実装。コミット・pushは未実施。

## 採用仕様

|転生回数|通常の有料攻撃技の追加威力|消費SP原価|聖光INT係数|
|---|---:|---:|---:|
|0|1|1|1.5|
|1|1.25|2|2|
|2|1.5|3|2.5|
|3|1.75|4|3|

対象はSP原価が正のphysicalAttack/spell。通常攻撃・チャージ・奥義・回復・補助・探索技は対象外。従来のレベル・転生補正は維持し、その上に追加威力を掛ける。成功率や持続時間は変更しない。

聖なる打撃は武器非依存の(STR+INT)×0.8とDEF無視を維持し、既存の物理レベル・転生係数を追加。共通追加威力も一度だけ掛ける。聖光は基礎値22・聖属性・必中・対アンデッド1.5倍を維持し、INT係数だけ上表へ変更する。

SP原価の倍率は装備・カード軽減前に適用する。水瓶座とマナの泉の無料条件、防具の条件付き割引を維持。既存のgetEffectiveSpCostを使うスキル画面の表示・選択可否・戦闘支払いが同じ計算を参照する。

## 実装

- combat/player-skill-scaling.js：対象判定、SP倍率、プレイヤーの攻撃解決直前の威力補正。
- combat/battle-engine.js：プレイヤーだけに補正。元の行動オブジェクトを書き換えず、対象・追加詠唱ごとに一度だけ適用する。敵・NPCへ適用しない。
- combat/sp-cost.js：原価に倍率を掛けてから既存の無料・軽減処理へ渡す。
- data/skills.js：聖なる打撃・聖光の説明文を更新。
- index.html：LAST UPDATEを2026-10-28へ更新。
- tools/compare-reincarnation-skill-candidate.mjs：本番採用後も、過去の現行/候補を再現する際は本番補正をプロセス内で外し、二重適用を防止。--production --probeは本番補正のまま検証する。

## 検証

node --test tests/*.test.mjs：2220件成功、失敗0、スキップ0。

追加6テストで全スキルの消費倍率と除外、転生0〜3の威力・僧侶係数、無料化と軽減順、双子座の複製、全体攻撃の一括支払い、敵側の同名呪文への非適用を確認。既存の転生防具テストは、原価4倍を反映した割引後コスト3SP/11SPへ期待値を更新した。
