# 転生防具（開発内部資料）

秘密のセット条件・効果を含む。README・公開更新案内へ転載しない。

## 実装範囲

2026-10-20、main/e2078ad6のクリーンな作業ツリーから実装。
12シリーズ48種、各0～+3の192定義。data/reincarnation-armor.jsへ分離し既存EQUIPMENTに統合。既存の装備個体、強化値解決、付与、装備確定、能力値集計、保存正規化を再利用。新防具は複数所持可。指定値は変更なし。
転生最低回数と職を装備確定でも検査。旧保存の新規フィールド欠落は許容。不適格な新防具の装備参照は正規化時に外し、所持個体は保持。上位転生でも下位防具を使用可。DEFの既存上限は維持。

**地図赤箱へ接続済み。** 2026-10-20追記：Lv91～100の4テーマの配置赤箱から入手可能。詳細はspecial-map-treasures.md。敵、商店、スタンプ景品への追加なし。売却基本価格（無強化／＋1／＋2／＋3）は、転生1段階7,000／8,500／11,000／20,000G、転生2段階8,000／9,500／12,000／25,000G、転生3段階9,000／11,500／13,000／30,000G。購入価格は未設定、店頭販売なし。開発用箱カタログの全装備列挙とは別に、赤箱専用の抽選経路へ接続。検証は正規付与/装備APIを利用。

## 通常効果・表示

既存魔法軽減、行動不能/出血/毒3種/奇襲耐性、回復奇蹟加算、攻撃呪文加算を再利用。
雷・闇・聖・地の直接ダメージ軽減を能力値集計と物理/呪文解決へ追加。各軽減上限75%、同種加算。魔法軽減とは別枠乗算。既存炎/氷の加算方式には変更なし。床/DOT/自傷/反射/SP減少には適用なし。敵側ハッキング補正とは独立で一度だけ適用。
新防具の通常効果・転生条件のみ表示。セット効果の説明/ゲージ/名前は追加なし。ステータスの転生防具行のみ2段にし、スマホで効果全文が切れないようにした。

## 非表示セット処理

combat/reincarnation-armor.jsで実際の装備個体ID、職、転生回数から判定。魔術師は頭胴足、他職は左頭胴足。混合シリーズ不成立、強化値混在可。両手武器の他職4部位は不成立。

- 戦士：実行した防御のラウンド終了、生存・戦闘継続中のみ2/2/3%回復。2/3段階の次の物理コマンドは10/15%強化、次ラウンドから2ラウンド。ミスで消費、多段・複製に共有、積み重ねなし。
- 盗賊：初物理コマンド10/15/20%、対象敵の行動機会未処理なら0/5/10%加算。行動不能/待機済みも行動済み扱い。初撃権は同一コマンド全ヒット/複製で共有。
- 僧侶：自分の回復奇蹟の実回復量の5/8/10%、最大HP5%上限の障壁。既存残量との最大値へ更新。発動ラウンドと次2ラウンドまで。軽減・既存障壁の後、HP減算と魚座生存判定の前に各ヒットから吸収。超過はHPへ通す。DOT等は対象外。死亡で障壁を消し、生存効果による復活でも戻さない。
- 魔術師：攻撃呪文（actionType:spell。呪文型チャージ/奥義を含む）を3コマンド実行後、4回目を強化。SP20/30/40%軽減、ダメージ0/10/15%増加。既存整数コストに乗算して切上げ、正のコスト最低1/元0は0。共通getEffectiveSpCostをUI/不足判定/消費で再利用。未実行は消費なし、ミス/無効は実行扱い。多対象/複製で周期を進めない。

状態はbattle.player.armorBattleのプレーン値、コマンド内補正はbattle.armorCommand。次コマンド/終了で補正を破棄。開始時は新規初期化、既存中断復元は状態を維持。既存goddessCheckpointのJSON往復で検証。通常戦闘に新たな中断保存経路を追加する変更ではない。
