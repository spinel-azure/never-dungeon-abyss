## 解放順序

1. 通常奈落でトレリーレンとの会話を3回完了。3回目は最初から依頼会話だけを表示する。4回目以降は調査協力をお願いする専用会話へ切り替える。
2. 酒場の「続・迷宮探検家の噂」（新規 `rumor_019`）を最後まで聞く。
3. 奈落入口の探検家テントが有効になり、地図探索βは名前のみ表示して無効のまま。
4. テントで署名を登録し、導入会話後に正式な「はじまりの白地図」3枚を受領。
5. βの注意書きと5つの説明を読み、既存鑑定画面へ進む。正式配布の3枚のうち1枚を鑑定・登録すると探索が永続解放される。

解放後は探検家テストOFFでも利用できる。開発用テスト機能は従来どおり独立して利用可能。
テント通常メニューの配置は前回仕様を維持。調査報告は無効、討伐報酬受領は未受領報酬がある場合だけ有効。

## 出会い・依頼の保存

- `character.trelirenProgress`：累計 `encounters`、依頼完了 `requestCompleted`、直近の加算済みID `lastEncounterId`。
- `character.trelirenRun.encounterId`：UUID。出会い開始時に確定し保存。中断・再接触・再ロードでは維持。
- 出会いの単位は「通常奈落の1探索」。既存処理は会話完了後、その探索中のトレリーレン出現を停止し、帰還で出現情報をリセットする。区域ごとに出現候補階が変わっても、同じ探索を別の出会いとして加算しない。
- 会話終了時に回数、加算済みID、依頼完了、探索内遭遇済みを一緒に保存。失敗時は巻き戻し、会話画面で再試行する。
- 回数がない旧セーブは `treliren_met=true` なら1回、未会話なら0回に移行。既にある回数は維持。正規化・ロードでは加算しない。
- 依頼会話は保存可能な会話phaseに追加。途中ロードではそのphaseから、キャンセル後の同一探索内再会話では会話冒頭から再開できる。
- 既存NPCタイプライターの速度設定・全文表示処理を共用。表示中の決定は全文表示、次の決定でページ送り。

## 酒場

汎用噂話定義に019を追加。017既聴、累計3以上、依頼完了が必要。正式白地図受領前は既聴でも現在の噂として再度聞ける。
既存の通知キューには未聴のときだけ載せ、再通知しない。正式配布後は受領後段階（received）が発生し、ローザの続きの台詞が初めて表示される。続きまで聞き終えると現在の噂から外れ、同じタイトルで過去の噂へ移る。続きの既聴は `tavern_rumor_019_received_read` で別保存する。
条件は現在のキャラクター情報から再評価するため、017を後から聞いた場合も成立する。
019の最終ページを確定するまで解放しない。既聴保存失敗時は解放を巻き戻して再試行を案内する。

## 正式配布・説明・鑑定

- 正式配布は既存 `starterMapsGranted`、テスト配布は `starterMapsTestGranted`。互いに権利を消費しない。
- 既存初期地図抽選を使用：WHITE固定、Lv1～5、16bit seed、登録署名、個別discovery ID。生成器・抽選方式は変更していない。
- `specialMaps.starterOffer` に確定済み3枚を先に保存。その後、所持地図への追加、配布済み記録、`formalStarterIds` を1回の地図トランザクションで保存し、成功後にのみジングルと画像・3枚の受領表示を行う。
- 配布保存失敗は巻き戻す。保存済みofferはロード後も再利用。offer保存自体が失敗した場合も、その画面内の再試行は保持済み抽選を再利用する。永続保存が一度も成功していない抽選は、アプリ終了をまたいで保証できない。
- 未鑑定上限3枚。既存未鑑定地図が1枚でもある場合は破棄せず、鑑定・整理へ案内して正式配布を保留する。
- `betaExplanationComplete` は説明終了時に保存。受領後の説明を中断しても、再訪時に説明冒頭から再開。再配布はしない。
- `formalStarterIds` に含まれる地図の既存鑑定・登録トランザクション内で `betaExplorationUnlocked` を保存する。保存失敗なら登録・解放とも巻き戻す。テスト地図や共有地図だけでは通常解放しない。
- 019既聴と探索解放は地図削除から独立。後で地図を削除しても取り消さない。
- 導入はテント背景と下部コマンドを使い、既存のタイプライター・ページ分割で表示。長文は画面幅に応じてさらに分割する。
